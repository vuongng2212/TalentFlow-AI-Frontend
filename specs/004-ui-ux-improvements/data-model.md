# Data Model: UI/UX Improvements

No new database entities or API schemas are required for this feature, as it primarily involves UI/UX refinements on static landing page components (CSS animations, layout updates, static content changes).

## Static Content Structure (Pricing)

The pricing tiers in the landing page will be updated to reflect the new structure:

*   **Free (Personal)**: One recruiter, two active jobs, AI parsing preview, and candidate notes.
*   **Plus (formerly Growth)**: Expanded CV parsing limits, candidate information synthesis, suited for individuals/freelancers.
*   **Business**: Enterprise features like ADMIN workspace creation, team collaboration (inviting interviewers/recruiters).
